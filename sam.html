SAM

Stock Assistant Mobile. Built to learn AI integration — took a family member's need as the vehicle and built a real voice-powered stock assistant with live market data.

iOS · Swift · SFSpeechRecognizer · Yahoo Finance API
ORIGIN

AI INTEGRATION. REAL NEED. ONE BUILD.

SAM started as a goal: build something that meaningfully integrates AI, not as a wrapper around a chatbot, but as a system where AI is the reasoning layer on top of real data. The vehicle was a family member who needed help navigating investing without the anxiety that comes from not knowing what the numbers mean.

That need shaped everything. SAM doesn't just show you a stock price — it talks to you about what that price means, listens to your voice, pulls live data, and responds in plain language. The result is a real voice assistant with SFSpeechRecognizer integration, live Yahoo Finance data, Charts framework rendering, and a conversation memory system that tracks context across the session.

HOW IT WORKS

THE VOICE PIPELINE

Every voice query moves through a real system — not a simple API call. Here's the full flow:

1
SFSPEECHRECOGNIZER
Apple's native speech recognition with proper permission handling, graceful fallbacks for denied/restricted states, and real-time transcription display while listening.
2
SYMBOL EXTRACTION
Regex-based ticker extraction from free-form speech. Company name resolver maps "Apple", "Tesla", "Google" to correct symbols. Falls back to 5-letter uppercase pattern matching.
3
YAHOO FINANCE API
Live market data via URLSession. Price, previous close, change percentage, exchange, volume. 30-day simulated historical data for chart rendering.
4
CHARTS FRAMEWORK
Swift Charts with LineMark + AreaMark. Up/down color-coded. Custom axis styling. Price rendered with gradient fill below the line.
5
CONVERSATION MEMORY
20-message rolling context window. Every user message and SAM response stored with timestamp. Context passed to response generation for coherent multi-turn conversations.
